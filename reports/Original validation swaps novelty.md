# Where original validation swaps could contribute

Research checked October 17, 2026. Historical comparison cutoff: **March 30, 2026**.

**The original project has a potentially distinctive diagnostic application, but its mathematical machinery is established and its present evidence does not establish a new inferential method.** The relevant question is whether we can learn an observable population on which proxy covariates cause acceptably little distortion, then decide whether borrowing proxy-only observations is worthwhile. That is different from selecting verification observations to improve an estimator for a fixed population. This review found no exact predecessor to the original attribution–domain–audit workflow; that is not proof of novelty. Its strongest mathematical claims reduce directly to baseline Shapley and multilinear extensions. Several implementation and inference problems also prevent the existing simulations from establishing the workflow's value. **Decision: narrow and test the application, after correctness repairs.**

This assessment concerns [commit `ab1c17f`](https://github.com/finite-sample/swaps/blob/ab1c17f230e2482e1f62887c45d708c26c190097/validation_swaps.tex), *Partial Credit: Diagnosing Proxy Covariates with Validation Swaps*, rather than the August outcome-correction rewrite. The repository's earliest verified record is March 30, 2026; the original README's 2025 citation does not independently establish earlier availability. February 2026 preprints therefore qualify as earlier work under this cutoff; post-March work is later than this verified repository record. This chronology does not establish when the author conceived the idea. ([Repository metadata](https://api.github.com/repos/finite-sample/swaps); [historical correction and background review](<ML measurement errors and inference.md>))

**The original proposal is more specific than “use influence functions for ML.”** It repeatedly replaces validated proxy covariates with truth and refits a coefficient, attributes the hybrid endpoint discrepancy to rows, predicts absolute attribution from observables, proposes a low-risk domain, audits its distortion, and considers local calibration and a precision–distortion tradeoff. Its code genuinely learns an observable score; it does not simply hardcode a favorable subgroup. Only validated rows are replaced, so the endpoint remains a hybrid unless every row is validated. The manuscript recognizes this limitation and describes its audit as a screen rather than a formal guarantee. ([Original manuscript, §§1–5](<../research_notes/Original validation swaps novelty/original_snapshot/validation_swaps.tex>); [original implementation](<../research_notes/Original validation swaps novelty/original_snapshot/replicate_final.py>))

| Original component | Closest established technology | Novelty assessment |
|---|---|---|
| Bernoulli replacement path | Owen's multilinear extension, evaluated at equal participation probabilities | Established mathematical object; coefficient-diagnostic application remains relevant. |
| Row attribution, SIM | Baseline Shapley applied to the refitted coefficient | Exact reduction, not a new attribution principle. |
| Predict absolute SIM from observables | Supervised prediction of a derived diagnostic | A useful candidate-generation heuristic; transport and decision value are unproved. |
| Select an observable domain | Selective prediction, inferential trimming, and filtered prediction-powered inference | Specific coefficient-distortion objective is distinguishable; exact predecessor not found. |
| Audit coefficient distortion | Equivalence testing and learn-then-test selection | Established architecture; validity for the complete proposed pipeline is unresolved. |
| Calibrate within the domain | Regression calibration | Existing principle; learning and selection require additional uncertainty analysis. |
| Trade bias allowance against standard error | Bias-aware inference | Not a new general decision principle; requires a justified bound for the deployed estimator. |

**The exact Shapley reduction is the strongest prior-art finding.** Fix the surrounding dataset and let \(v(S)\) be the coefficient obtained by correcting validated rows in \(S\), retaining every row. This is baseline Shapley: input coordinates switch from a fixed baseline to their specified replacements, and the scalar function is a regression refit. Sundararajan and Najmi's ICML 2020 paper gives precisely that construction in §2.2, equation (3). Changing the function from a prediction to a coefficient changes the interpretation, not the attribution mathematics. ([*The Many Shapley Values for Model Explanation*](https://proceedings.mlr.press/v119/sundararajan20b/sundararajan20b.pdf))

The path and attribution are two views of the same established construction. If \(F(q)\) is the multilinear extension of \(v\), and \(a_i(p)\) is the expected marginal contribution of row \(i\) when each other row is independently corrected with probability \(p\), then our direct reduction gives

\[
 \phi_V(p)=F(p\mathbf 1),\qquad
 \mathrm{SIM}_i=\int_0^1 a_i(p)\,dp,\qquad
 \sum_i\mathrm{SIM}_i=v(V)-v(\varnothing).
\]

Owen introduced multilinear extensions in 1972. Okhrati and Lipani's 2020 preprint, §III equations (2)–(3), supplies the probabilistic Shapley representation and develops sampling algorithms. The identity follows by integrating the Bernoulli coalition weights; it supplies no new domain-selection or transport guarantee. ([Owen, publisher record](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.18.5.64); [probabilistic representation](https://arxiv.org/pdf/2010.12082))

Neighboring applications should not be overstated. Data Shapley values the inclusion of training rows; DataScope applies inclusion-based valuation to pipelines and label-repair prioritization. Deutch and colleagues explain why a repair algorithm changes a database cell. None is the same game as retaining all rows and attributing how verified replacements change an econometric coefficient. They show that attribution and cleaning were already connected, but do not establish publication of this exact diagnostic. ([Ghorbani and Zou, §2](https://proceedings.mlr.press/v97/ghorbani19c/ghorbani19c.pdf); [DataScope, §§2, 5](https://proceedings.iclr.cc/paper_files/paper/2024/file/ccdd1961dcd0245d9dadceccead0fad1-Paper-Conference.pdf); [Deutch et al., §3](https://amirgilad.github.io/publication/cikm21/CIKM21.pdf))

**Domain selection is the more plausible source of a contribution.** Xu and Sun's *Filtered Prediction-Powered Inference*, first submitted February 11, 2026, is a close pre-cutoff comparator. It learns regions where predictions improve inference. Its GLM objective, equations (12)–(13), retains the full labeled-data loss and filters only the prediction correction: it preserves the full-population target. The original swaps manuscript instead restricts the target population and seeks small coefficient distortion there. FPPI is therefore a strong comparator, not an exact duplicate. It sharpens the practical question: when is restricting the population preferable to retaining the target and selectively using predictions? ([Submission record](https://arxiv.org/abs/2602.10464); [FPPI, §§2–4](https://arxiv.org/pdf/2602.10464))

Other ingredients are older. Selective classification formalizes the tradeoff between retained share and error; Crump and colleagues choose subpopulations for more precise causal estimation, changing the estimand to address overlap. Neither targets proxy-induced coefficient distortion. ([El-Yaniv and Wiener, 2010](https://www.jmlr.org/papers/volume11/el-yaniv10a/el-yaniv10a.pdf); [Crump et al., 2009](https://dash.harvard.edu/entities/publication/73120378-86bc-6bd4-e053-0100007fdf3b)) Active Statistical Inference and Kluger–Bates address target-specific verification allocation; they do not by themselves duplicate this original domain-audit objective. ([ASI, §7](https://arxiv.org/html/2403.03208v2); [Kluger–Bates, §4](https://arxiv.org/html/2602.16933v1))

Predicting absolute attribution does not establish domain safety. Restriction changes regression geometry, and large signed contributions can cancel. Consequently, thresholds can generate nested domains without monotone coefficient distortion. A flat mean swap path can also reflect cancellation or the small fraction of corrected rows. These are limits on the inference from the diagnostic, not reasons to discard it.

The proposed uncertainty-aware audit is a coefficient-equivalence screen: require an interval for the paired gold–proxy difference to lie inside a substantive tolerance. Equivalence testing for regression coefficients is established, although Counsell and Cribbie's displayed comparison assumes independent coefficients rather than this paired design. Learn Then Test supplies an architecture for selecting among multiple certified candidates when their tests are valid. Neither reference provides the missing proof for this complete coefficient-distortion pipeline. ([Counsell and Cribbie, 2015, §4](https://yorkspace.library.yorku.ca/server/api/core/bitstreams/dd1ac706-b3e5-4df2-98fe-413c639df601/content); [Learn Then Test, Theorem 1](https://arxiv.org/pdf/2110.01052))

Local calibration likewise draws on established conditional-expectation arguments. Its proposition needs relevance and suitable exogeneity; it does not justify arbitrary estimated calibration or its reported standard errors. Adding a distortion allowance to an interval also requires that allowance to bound the actual estimator's bias. A point audit cannot supply that bound. ([Spiegelman et al., 2011, §2](https://www.degruyterbrill.com/document/doi/10.2202/1557-4679.1259/pdf); [Armstrong et al., §2, equation (6)](https://arxiv.org/pdf/2012.14823))

**The implementation currently prevents a clean test of the claimed contribution.** Most decisively, `compute_sim` samples every other correction with probability one-half. It estimates the midpoint marginal contribution \(a_i(1/2)\), a probabilistic Banzhaf value, rather than the Shapley integral. In an exact five-player OLS game, the endpoint gap and Shapley sum both equal **0.08743199**; the Banzhaf sum is **0.08046967**. The original algorithm with 20,000 draws agrees much more closely with Banzhaf. More draws cannot repair the weighting. This is a correctness defect, separate from whether the proposed Shapley application is useful. ([Audit and exact enumeration](<../research_notes/Original validation swaps novelty/original_audit.md>); [machine-readable results](<../research_notes/Original validation swaps novelty/verification_results.json>))

The audit and deployment also concern different estimators. The code audits raw-proxy versus gold coefficients, then reports a locally calibrated regression. Passing the first check does not certify the second. Discovery attributions use the full outcome vector, including audit outcomes; only audit gold covariates are withheld. Thus the ordinary independent-outcome holdout argument is unavailable without further analysis. The manuscript's explicit caution about a nonformal audit is appropriate, but its precision claims still need validation of the actual pipeline. ([Source audit, findings 4–5](<../research_notes/Original validation swaps novelty/original_audit.md>))

Calibration uncertainty matters even before domain selection. In an isolated **300-replication** full-domain check using the original heterogeneous DGP and calibration code, the mean reported SE was **0.0659**, versus empirical SD **0.1077**; nominal 95% intervals covered the target **74.3%** of the time. This targeted counterexample shows that treating fitted calibration as fixed understates uncertainty here. It is not a complete coverage evaluation of every domain policy. ([Verification results](<../research_notes/Original validation swaps novelty/verification_results.json>))

The simulation interpretation also needs repair. In the “ugly” DGP, substitution yields a gold regression coefficient of **2**, not the stated 1. Its conditional mean \(E[X\mid Z]=W_2\) is correctly linear, but calibration has no separate identifying variation beyond the controls. This is a relevance failure detectable by standard diagnostics. In the heterogeneous DGP, the true conditional mean is nonlinear, yet linear-projection calibration can still recover the coefficient under the stated outcome structure. Conditional-mean misspecification therefore does not establish coefficient bias. Neither example establishes a distinctive advantage in diagnosing correction failure. ([Algebra and numerical checks, findings 2–3](<../research_notes/Original validation swaps novelty/original_audit.md>))

**A decisive next comparison should test useful domain selection, not attribution identities.** Start with paired proxy/gold data and one prespecified coefficient. Split discovery, audit, and assessment genuinely; freeze the domain and deployed estimator before auditing, or supply a valid dependence argument. Compare learned domain proposals from actual Shapley, Banzhaf, exact single-row replacements, and paired-score influence approximations. Add simple observable screens and direct coefficient-equivalence domain search. Give every method the same labels, candidate-domain class, certification rule, and computational accounting. Uniform validation is the sampling reference; modern correction and validation-only estimates are appropriate comparisons when evaluated on the same target domain. FPPI can separately assess the value of retaining the original population target.

The outcome is reliably retained population share or verification cost at a prespecified distortion tolerance, with false certification, coverage, relevance, and fallback behavior measured on untouched data. Report domain-specific targets explicitly. Predefine a meaningful improvement and evaluate repeated samples and a second setting; do not select a favorable subgroup retrospectively. Shapley should earn its repeated-refit cost through better decisions than cheaper scores. A new guarantee would need a nontrivial result about the actual distortion functional and selection procedure, rather than a relabeling of sample splitting, equivalence testing, and Learn Then Test.

Continue toward a methods paper only if such an advantage or theorem survives. If inexpensive scores or direct equivalence search perform as well, retain swaps as an explanatory diagnostic. If calibration relevance checks explain the apparent advantage, do not attribute it to row allocation. The current verdict is **possible distinctive application, unproved methodological novelty**, rather than either “already identical to PPI” or “new because no exact title matched.”
